# ADR-007: 第三者コンテンツとブランドの保護

Status: accepted
Date: 2026-09-13

Context:
本サービスは一般的な習慣形成の知見を利用するが、特定書籍の表現、翻訳、図表、ワークシート、固有の構成、ブランド表示を再現すると、著作権、商標、出所混同等のリスクが生じる。promptだけではモデルの出力を保証できず、出典表示だけでも無許諾利用の問題は解消しない。

Decision:
- 一般的な方法・アイデアと保護され得る具体的表現を区別し、プロダクトでは前者を独自の用語、構成、文章、UIとして提供する。
- 特定の書籍・著者・ブランドの名称、本文、翻訳、図表、ワークシート、表紙、ロゴ、固有の具体例や説明構成を、権利確認なく製品素材、prompt、RAG、fixture、販促へ使用しない。
- 第三者資料をAIへ投入する場合は、権利根拠と許可用途を記録したallowlistに限定する。
- AI出力はprompt制約に加え、Application層の決定論的validatorで検査する。疑義がある結果は表示・保存せず、第三者固有表現を含まないversioned fallbackへ切り替える。
- 商品名、機能名、販促、第三者素材の収録、公開引用はAIに最終判断させずhuman reviewを必須とする。
- 本サービスが第三者の公式、提携、監修、公認であるとの誤認を生む表示を禁止する。

Alternatives considered:
- promptだけで禁止する: 出力保証と監査可能性が不足するため採用しない。
- 出典表示があれば利用可能とする: 引用・ライセンス要件を満たすとは限らないため採用しない。
- 特定書籍の用語と構成をそのまま採用する: ブランド混同と表現再現のリスクが高いため採用しない。

Consequences:
- AI contract、validator、fallback、権利資料registry、adversarial evalが必要になる。
- validatorのfalse positiveを測定し、一般的な助言まで過剰に拒否しないようhuman-reviewed fixtureで調整する。
- 法的適否の保証ではないため、公開名称・素材・販促と対象地域拡大には専門家レビューが引き続き必要になる。

Security/operational impact:
- 拒否理由はコードと件数だけを監査し、問題となった本文は通常ログへ残さない。
- 権利資料registryの変更はレビュー必須とし、期限切れ資料を自動的に利用対象外にする。
- validator停止時はfail closedとし、AI提案を表示せず安全なfallbackを返す。
